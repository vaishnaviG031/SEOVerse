YOUTUBE SEO AGENT — LOCAL STARTUP

1. Open PowerShell in this project folder:
   C:\Users\DELL\Downloads\youtube_seo_agent_v1_crewai-project

2. Start Ollama if it is not already running:
   ollama serve
   (If Ollama is already running, do not start a second copy.)

3. In a SECOND PowerShell terminal, start the local web app:
   Set-Location 'C:\Users\DELL\Downloads\youtube_seo_agent_v1_crewai-project'
   $env:MODEL='ollama/llama3.2:1b'
   $env:PYTHONUTF8='1'
   $env:PYTHONIOENCODING='utf-8'
   $env:PYTHONUNBUFFERED='1'
   .\.venv\Scripts\python.exe -m uvicorn api_server:app --host 127.0.0.1 --port 8000

4. Open this address in your browser:
   http://127.0.0.1:8000

5. Enter a topic and select Generate SEO strategy. The report is saved to:
   reports\latest_report.md

NOTES
- The language model runs locally through Ollama. Keep MODEL set to ollama/llama3.2:1b.
- Do not share .env or api.env; they can contain private API credentials.
- The first full agent run may take several minutes on an 8 GB RAM laptop.
- A successful page load only verifies the UI/API server. A completed report verifies the full workflow.
